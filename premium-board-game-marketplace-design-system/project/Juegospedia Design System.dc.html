00 Brand & identity

The mark & the wordmark

The meeple is tabletop's universal token — the moment you see one, you know you're among games. We seat it in a rounded tile that reads as both a game box and an app icon. Two ideas, one mark: play & catalog.

Mark exploration

Three routes considered. The meeple-in-tile wins on instant recognition and works from 512 px down to a 16 px favicon; the others live on as supporting motifs.

Chosen
Meeple in a tile

Universal game token + box/app container. Solid silhouette holds at any size.

Considered
The die

Clean, but dice belong to every game. Too generic to own.

Motif
Hex knockout

Tile-laying nod. Kept as a felt-green pattern motif, not the primary mark.

Social rules

Layout
  • 1080 grid, 64 px safe margin on every edge
  • Mark + mono kicker top-left, stat line bottom
  • One idea per post — never two headlines
Accent rotation

Rotate clay → gold → forest → felt down the grid so three-in-a-row never repeats a background.

Voice & tags

Encyclopedia-precise, never hype. State the fact, then the price.
